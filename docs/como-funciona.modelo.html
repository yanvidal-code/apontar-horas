apontar-horas por dentro

A skill preenche a planilha de horas do ClickUp com o que ficou registrado no seu dia: as conversas com os agentes, o que você fez no GitHub (push, PR, review, comentário) e os seus comentários nas tasks do ClickUp. O que dá para decidir por regra fica num script determinístico; o que exige leitura fica com o LLM; quem grava é você.

Para usar

  1. gh auth login, se ainda não fez. É opcional: sem ele a fonte GitHub fica de fora e o resto funciona.
  2. ./apontar ontem na raiz do mind. Na primeira vez ele pede o token do ClickUp (avatar → Settings → Apps → API Token) sem mostrar o que você digita. Não precisa de Xcode: o programa da digital já vem pronto.
  3. O agente lê o dia, propõe e abre a tela local. Você confere, ajusta início e fim, e grava.
